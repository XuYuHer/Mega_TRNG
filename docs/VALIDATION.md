# 验证记录 — 2026-09-26

环境：Windows、PlatformIO Core 6.2.0、Atmel AVR 5.3.0、
Arduino AVR framework 5.4.0、avr-g++ 7.3.0、Python 3.14.5。
当前只枚举到蓝牙 COM 口，未发现 Mega USB 串口，**未烧录、未取得实板速度或熵源质量数据**。

## 软件开销对比

使用 `python tools/benchmark_avr.py --baseline-ref 11cb990`，
分别编译旧库和当前库，在 AVR 指令模拟器中输入相同的确定性 ADC 替身序列。
参数为 `-Os -flto`、ATmega2560、Timer1/WDT 编译关闭、四平面代码保留、
预热 64 个样本、生成 256 字节。报告包括启动、输入替身和生成循环的总周期。

| 路径 | 旧版周期 | 当前周期 | 周期减少 | 两版消费样本 / 接受位数 |
|---|---:|---:|---:|---|
| 单平面 LSB | 9,758,622 | 7,215,309 | 26.06% | 8,474 / 2,048 |
| 四个位平面 | 3,667,708 | 2,563,582 | 30.10% | 2,070 / 2,048 |

两版对应的输出校验值分别一致：单平面 `2637238138`，四平面 `3895633851`。
优化保留了去偏规则、健康阈值和混合器；主要减少逐平面变量移位、重复配对状态操作、
逐位清空缓存和无效硬件访问。模拟器**没有真实 ADC 转换等待、串口发送和中断抖动**，
这些百分比只说明软件周期减少，不能直接声称实板吞吐提高相同比例。
机器可读结果保存在 `artifacts/avr_benchmark.json`，模拟日志位于 `.pio/avr-benchmark/`；
都可以通过上述命令重新生成。

`pio run -e megaatmega2560 -e megaatmega2560_min -e megaatmega2560_coin -e megaatmega2560_adcdiag` 全部通过。

| 环境 | Flash | 静态 RAM |

| `megaatmega2560` | 9,448 B | 532 B |
| `megaatmega2560_min` | 8,842 B | 529 B |
| `megaatmega2560_coin` | 5,346 B | 513 B |

演示固件增加了格式化的批量速度统计，包含 Arduino 浮点打印支持；
采集固件不做统计/绘图，也不使用浮点打印。所有构建都远低于 Mega 的 Flash/RAM 容量。
Basic、Benchmark、Turbo 三个 Arduino 示例也已通过 `pio ci` 编译。

## 回归检查

`python tools/check.py` 通过 14 项电脑端测试和两种位平面编译配置的原生 C++ 检查。
覆盖内容包括：

- 精确的非整字节次数、检查点位置、分块一致性、全正/全反输入及输入不足。
- CRC 已知向量、任意分段串口读取、启动杂字节、序号回绕、丢帧/重复/复位、
  帧截断、协议字段错误、超时、板端故障、采集模式不一致、捕获文件重放。
- 实际 `TRNG.cpp` 在可控 ADC 输入下，所有有效掩码的接受位计数、
  `next(out, 1)` 与阻塞读取的一致性、故障后不输出、重复/比例健康检查、
  单实例独占、A0～A15 配置及寄存器恢复。

原生 ADC 寄存器替身用于算法/状态测试；实际寄存器时序和噪声性质仍需板上验证。

| 抛掷次数 | 正面比例 | 相对 0.5 的误差 |

正面 500,451 次，反面 499,549 次。图中展示累计频率与绝对误差的变化；
这份结果明确标为电脑伪随机模拟，不代表 Mega 的真实噪声结果。
